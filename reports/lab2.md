# 问答作业
1. ​​SV39 页表项（64 位）结构​​：
   + ​​PPN[2:0]​​（44 位）：三级页表的物理页号（PPN）
   + ​Reserved​​（10 位）：保留位（通常为 0）。
   + Flags​​（10 位）：标志位，包含以下关键标志：
      + V（Valid）：页表项是否有效。
      + R（Read）：允许读操作。
      + W（Write）：允许写操作。
      + X（Execute）：允许执行操作。
      + U（User）：用户态可访问（若 U=0，仅内核态可访问）。
      + A（Accessed）：页表项是否被访问过（用于页面替换算法）。
      + D（Dirty）：页表项是否被修改过（用于写回策略）。
      + RSW（2 位）：保留给操作系统使用的自定义标志。
  
2. + ​​LoadPageFault​​：加载操作访问无效页；​​StorePageFault​​：存储操作访问无效页；​​InstructionPageFault​​：执行操作访问无效页
   + ​​stval​​：存储触发缺页的虚拟地址；​scause​​：存储异常原因（如 0xC 表示加载缺页）；​​sepc​​：存储触发缺页的指令地址（PC 值）
   + ​​减少内存占用​​：仅实际使用的页面分配物理内存；​​加速进程启动​​：无需预先加载全部代码/数据；​​节省资源​​：避免无意义的页表操作（如示例中的 10G 仅用 1M）
   + 10G = 2,621,440 个 4KB 页；每个页表项占 8 字节，总大小约 ​​20MB​​（三级页表总和）
   + ​​实现步骤​​：
​     1. ​标记保留区域​​：记录虚拟地址对应的数据位置（如磁盘或零页）
​​     2. 缺页处理​​：
        根据虚拟地址找到数据源（如磁盘或新建零页）；
        分配物理页，填充数据；
        更新页表项为有效并设置权限；
        重新执行触发缺页的指令；
   + V=0（无效），其他标志位可能存储磁盘位置信息（如 swap 分区偏移）；OS 换入页面后，更新 PTE 为 V=1 并指向新物理页

3. + ​​更换页表​​：任务切换时修改 satp 寄存器；​
   + ​权限控制​​：通过 PTE.U=0 标记内核页，用户态访问时触发异常。
   + 上下文切换快​​：无需切换页表；​​TLB 效率高​​：内核与用户共享地址空间，减少 TLB 刷新
   + ​​双页表切换时机​​：​​用户态→内核态​​：切换到内核页表，​内核态→用户态​​：切换回用户页表。单页表更换时机​​：​​进程切换时​​：修改 satp 指向新进程页表，无需模式切换​​：内核与用户共享页表，仅通过权限位隔离
